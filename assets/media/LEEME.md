# Tus archivos multimedia

Pon aquí tus archivos y referéncialos en `config.js` con la ruta `assets/media/...`:

- `background.mp4` / `background.gif` → fondo (`background.url`)
- `cancion.mp3` → música (`audio.tracks[].url`)
- `avatar.png`, `cursor.png`, `decoracion.png`…

Consejo: comprime los videos (menos de ~15 MB) para que el perfil cargue rápido.
GitHub no acepta archivos de más de 100 MB.
