Conectar con GitHub

Para guardar directamente, el editor necesita un token personal de tu cuenta de GitHub. Se crea una sola vez:

  1. Abre github.com/settings/personal-access-tokens/new
  2. Token name: "Editor de perfil". Expiration: la que quieras (puede ser sin vencimiento).
  3. Repository access → Only select repositories → elige este repositorio.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Pulsa Generate token, cópialo y pégalo aquí abajo.

El token solo se guarda en tu navegador y solo se envía a api.github.com. Nunca se sube al repositorio.
